# Q-SHIELD

### BB84 Quantum Key Distribution for Cybersecurity

Q-SHIELD is a quantum cybersecurity project that uses the BB84 protocol to demonstrate secure key distribution and eavesdropping detection.

The project simulates Alice, Bob, and Eve, measures QBER, applies key post-processing, and explores the use of QKD with Post-Quantum Cryptography.

### Features
- BB84 QKD simulation
- Eve attack simulation
- QBER analysis
- Channel noise modeling
- Error correction & privacy amplification
- QKD vs ML-KEM comparison

### Tech Stack
React • TypeScript • Python • FastAPI • Qiskit • Qiskit Aer • PostgreSQL
